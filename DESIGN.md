# Design rationale

- **Dark, high-contrast canvas, one loud accent.** Generated media is the hero; neutral surfaces make it pop, and a single accent (Lime/Violet/Ember/Ocean) marks the primary action everywhere. Accent text colours are chosen for WCAG AA against `--accent-fg`.
- **Accent switcher in the header.** Cheap personalisation creates ownership and a reason to poke around. It persists in a cookie (read server-side, so no flash) and localStorage.
- **Credits chip always visible.** A constant, tappable reminder of balance fuels the claim-streak loop and makes the upsell feel natural.
- **Centre Create button on phones.** The loop is see, remix, generate; the primary verb sits under the thumb.
- **Motion with purpose.** Skeleton shimmer instead of spinners keeps the wait feeling alive; the flame pulse rewards streaks. All motion collapses under `prefers-reduced-motion`.
- **Ergonomics.** 44px targets, safe-area padding, a single responsive nav (bottom bar, rail, sidebar), no horizontal scroll at 320px.
- **Light, dark and system themes.** Dark stays the default; `light` and `system` (follows `prefers-color-scheme` live) are one click away in the header menu, the colour popover and Settings. Everything is driven by CSS variables switched on `:root[data-theme]`; an inline boot script sets `data-theme`, `theme-color` and `color-scheme` before first paint (no flash), and a short-lived `theme-fade` class crossfades colours without animating every property. Light text/borders are tuned to AA (body ~16:1, muted ~6:1). Semantic tokens (`danger`, `success`, `warn`, `earn`, `scrim`) replace hard-coded Tailwind palette colours; overlays on media (hero veil, post captions) use token-driven gradients so text stays legible in both themes.
- **Accent x theme.** `--accent` is the fill; `--accent-fg` the text on it (AA either way); `--accent-text` (aka accent ink) is the same hue shifted for text/icons/links: lightened on dark, darkened on light (>= 4.9:1). Custom colours carry pre-derived inks for both themes (`--accent-text-d/-l`), so flipping the theme never needs JS. `ensureUsableAccent(hex, min, mode)` nudges lightness against the current background.
